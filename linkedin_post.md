# ☕ Cafe Paradise — Full-Stack Coffee Shop Management System

I'm excited to share my latest project: **Cafe Paradise**, a complete coffee shop management system built with modern web technologies!

## 🎯 What It Does

Cafe Paradise digitizes the entire coffee shop experience:
- **Customers** scan table QR codes to browse the menu and place orders
- **Kitchen staff** receive orders instantly and update preparation status in real-time
- **Admins** manage menu items and staff accounts through a comprehensive dashboard
- **Customers** track their order status live without refreshing the page

## 💡 Key Features

✅ **QR Code Ordering** — Customers scan table QR codes to access the menu
✅ **Real-time Updates** — Socket.IO powers live order tracking for customers and kitchen
✅ **Role-based Access** — Separate dashboards for Admin, Kitchen, and Waiters
✅ **Order Management** — Complete workflow from order → preparing → ready → served
✅ **Responsive Design** — Works seamlessly on desktop and mobile devices

## 🛠️ Tech Stack

**Backend:**
- Node.js + Express.js
- MongoDB + Mongoose
- Socket.IO for real-time communication
- bcrypt for password hashing

**Frontend:**
- Vue 3 (Composition API)
- Vite
- Vue Router 4
- Axios + Socket.IO Client

## 🚀 What I Learned

This project strengthened my skills in:
- Real-time bidirectional communication with Socket.IO
- Role-based authentication and authorization

## 📊 Project Highlights

- 3 user roles (Admin, Kitchen, Waiter)
- 10 table QR codes for customer access
- Real-time order tracking

## 🔗 Why This Matters

This is a production-ready solution for small to medium coffee shops looking to modernize their ordering process. It demonstrates modern full-stack development practices with a focus on real-time user experience.
